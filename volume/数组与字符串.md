## 交替地将两个字符串合并

> You are given two strings `word1` and `word2`. Merge the strings by adding letters in alternating order, starting with word1. If a string is longer than the other, append the additional letters onto the end of the merged string.
>
> 给你两个字符串 `word1` 和 `word2`。从 `word1` 开始以交替形式合并两个字符串。如果某个字符串太长了，那么直接把剩余的合并进去。
>
> Return the merged string.
>
> 返回合并后的字符串。


```c
char * mergeAlternately(char * word1, char * word2){
    char *ans = (char*) calloc(256, sizeof(char)); // static char *ans[256];
    size_t n = strlen(word1), m = strlen(word2), i = 0, j = 0, k = 0;
    while (i < n && j < m) {
        ans[k] = word1[i++];
        ans[k + 1] = word2[j++];
        k += 2;
    }
    strcpy(ans + k, i >= n ? word2 + j : word1 + i);
    return ans;
}
```

想象你有两张纸条，谁长谁短其实难说，不过只要把它们摆到桌面上，一切都好操作：从左边开始一段一段地切下来，先切上面的，再切下面的。

## 字符串的“最大公约数”

> For two strings s and t, we say "t divides s" if and only if s = t + t + t + ... + t + t (i.e., t is concatenated with itself one or more times).
>
> 对于两个字符串 `s` 和 `t` ，但其仅当 `s = t + t + t + ... + t + t` 成立时，我们说“`s` 可以被 `t` 整除”。
>
> Given two strings str1 and str2, return the largest string x such that x divides both str1 and str2.
>
> 给你两个字符串，返回这两个字符串的“最大公约数”

```cpp
class Solution {
public:
    string gcdOfStrings(string s, string t) {
        if (s.size() > t.size()) swap(s, t);
        int n = s.size();
        string ans {};
        for (int i = 1; i <= n; i++) {
            auto p = s.substr(0, i);
            int m = p.size();
            bool ok = true;
            for (int j = 0; j < t.size(); j += m) {
                if (p != t.substr(j, m)) {
                    ok = false;
                    break;
                }
            }
            for (int j = 0; j < s.size(); j += m) {
                if (p != s.substr(j, m)) {
                    ok = false;
                    break;
                }
            }
            if (ok) ans = p;
        }
        return ans;
    }
};
```

## 拥有最多糖果的小孩子

> There are n kids with candies. You are given an integer array candies, where each `candies[i]` represents the number of candies the ith kid has, and an integer extraCandies, denoting the number of extra candies that you have.
> 
> Return a boolean array result of length n, where `result[i]` is true if, after giving the ith kid all the extraCandies, they will have the greatest number of candies among all the kids, or false otherwise.
>
> Note that multiple kids can have the greatest number of candies.

```cpp
class Solution {
public:
    vector<bool> kidsWithCandies(vector<int>& candies, int extraCandies) {
        auto max = std::ranges::max(candies);
        vector<bool> ans(candies.size());
        for (int i = 0; i < ans.size(); i++) {
            ans[i] = candies[i] + extraCandies >= max;
        }
        return ans;
    }
};
```
