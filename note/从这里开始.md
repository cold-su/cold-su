# 从这里开始

我已经很久没有写过文字了。想起当初为了写满一张纸，兴致勃勃地看了一晚上的钢笔，又花了相对于我的零花钱来说的大价钱买了几支钢笔；又为了写成一本厚度不错的书，满天星地写想法，群蚁排衙地铺满枯草黄色的草稿纸；接着收录到……收录到哪里去了呢，我也没有头绪了。

如果那时候有追求，那么就是想要尽可能多地写，同时尽可能多地仿，然后得到一篇字数看起来不错的文章，接着得意洋洋地收藏起来。然而我那时候的“保管”意识是严重欠缺的，藏得好，最终就是找不到。还有一部分是我自己扔到废纸篓里面的，至于理由，也一并扔进去了；我讨厌字数统计。

现在我不再看以前的东西了，我找到了一个很好的概念，那是圆，环绕，持续，和无穷无尽。Pi-agent 的源码导读给了我很好的启发。

我不敢确定未来会更新什么，但是我可以确定未来什么时候能再次见面。

慢慢来，一周只长一章。
